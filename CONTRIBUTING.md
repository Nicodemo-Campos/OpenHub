# Contributing to OpenHub

Thanks for your interest in OpenHub.

OpenHub is currently in an early architecture phase and uses a noncommercial source-available license with a planned separate commercial-licensing path.

For that reason, the project **does not yet accept substantive third-party code contributions** until explicit contributor/relicensing terms are published.

You are welcome to:

- open bug reports;
- share device-detection reports with private identifiers removed;
- suggest hardware or protocol documentation;
- propose architecture ideas in an issue.

Please open an issue before preparing a code contribution.

This temporary policy avoids creating ambiguous rights around future commercial licensing. A formal contribution policy can replace it once the project is ready for external contributors.
